# Evidence policy

This public tree contains sanitized summaries only. Raw logs, memory dumps,
session material, VM identifiers, internal addresses, and command-execution
artifacts remain in restricted storage.

The summary files are derived from retained reports. Before public release,
their hashes and an internal chain-of-custody manifest should be generated from
the frozen evidence set.

`fpm-stale-state-summary.csv` records only the verified outcome summary. The
underlying kernel and FPM logs remain in restricted storage until they are
frozen and sanitized.
